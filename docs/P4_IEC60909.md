### Z0 de fuente

P2 almacena R0/X0 absolutos por escenario. Para pandapower:

```text
r0x0 = R0 / X0
x0x  = X0 / X1_backend
```

`X1_backend` usa el mismo escenario Scc/X-R y factor de tensión del backend. Los tests verifican preservación del R0/X0 absoluto. `X0=0` no se aproxima silenciosamente.

### Z0 de líneas

Cada línea debe declarar:

- `r0_ohm_km`;
- `x0_ohm_km`;
- `c0_nf_km`.

`C0=0.0` es válido si fue declarado; **ausencia de C0 no equivale a cero**. MIN exige `endtemp_degree` explícita y pandapower corrige R1/R0.

### Z0 de transformadores y neutro

La ficha P2 se proyecta mediante:

- `vk0_percent`;
- `vkr0_percent`;
- `mag0_percent`;
- `mag0_rx`;
- `si0_hv_partial`;
- `rn_ohm/xn_ohm` cuando corresponden;
- grupo vectorial efectivo y neutro explícito.

Un transformador sin ficha Z0 proyectable o un devanado wye sin declaración de neutro bloquea readiness.

### Resultados 1F-T

Se promocionan:

- `Ik''`;
- Rk/Xk;
- Rk0/Xk0.

No se promocionan actualmente:

- `Sk''` contractual 1F-T;
- `ip`;
- `Ith`.

El navegador tampoco los deriva.

### Benchmark independiente 1F-T

La referencia usa componentes simétricas:

```text
If = 3 * E / (Z1 + Z2 + Z0)
Z2 = Z1
Ik''_1F-T = sqrt(3) * c * Un / |2*Z1 + Z0|
```

El benchmark cubre MAX/MIN, Rk/Xk y Rk0/Xk0. Adicionalmente, un caso Dyn11 comprueba que introducir impedancia de neutro reduce físicamente la corriente 1F-T.

## P4C08 — estrategia 2F-T

**DONE por exclusión explícita de P4-v1.**

Pandapower 3.5.4 `calc_sc()` acepta únicamente `3ph`, `2ph` y `1ph`. No existe un token directo 2F-T en el backend versionado.

Por tanto:

```text
fault = two_phase_ground
status = OUT_OF_SCOPE_P4_V1
backend_api_supported = false
p4_v1_candidate = false
no_approximation = true
```

Se rechazaron tres atajos:

1. renombrar `2ph` como 2F-T;
2. renombrar `1ph` como 2F-T;
3. introducir un solver MCP paralelo sin contrato/benchmark/revisión propios.

Reingreso futuro requiere soporte directo del backend o un solver MCP dedicado con contrato de resultados, secuencias, benchmark independiente, CI, revisión IEC 60909-0:2026 y representación visual.

Detalle: `docs/P4C08_2FT_SCOPE.md`.

## P4C10 — revisión IEC 60909-0:2026

**DONE CON LIMITACIONES EXPLÍCITAS.**

La revisión versionada vive en `mcp_electrico.iec60909_conformance` y en `docs/P4C10_IEC60909_2026_REVIEW.md`.

Resultado contractual:

```text
target_edition_conformance = REVIEWED_WITH_LIMITATIONS_AGAINST_TARGET_EDITION
full_conformance_claim = false
```

La evidencia pública confirma la edición 3.0, el método de fuente de tensión equivalente, el objetivo MAX/MIN y las categorías de falla. La edición 2026 declara una revisión técnica con reestructuración/complementación especialmente del Capítulo 6 de modelado de equipos. Por eso P4C10 **no** usa `VERIFIED_AGAINST_TARGET_EDITION`: no se afirma una comparación exhaustiva ecuación-por-ecuación de toda la norma.

Limitaciones relevantes para P4-v1:

- generadores, motores, convertidores, unidades de generación, FACTS/HVDC fuera del alcance;
- 2F-T fuera del alcance por P4C08;
- `Ib` de corte y `Ik` permanente no promocionados;
- `ip/Ith` 1F-T no promocionados;
- una verificación integral futura requerirá acceso controlado al texto completo licenciado y matriz de trazabilidad normativa.

P4C10 cierra la revisión de edición, **no** una afirmación de conformidad integral ni la emisión profesional.
